# java-racingcar-precourse

## 목표
- 단일 역할을 수행하는 작은 함수로 분리
- 테스트 사용
- 1주차 피드백 반영
  - 커밋 메시지 의미 있게 작성
  - 오류 찾을 때 디버거 사용
  - 이름을 통해 의도 드러내기
  - Java에서 제공하는 API 적극 활용

## 기능 목록
- 경주할 자동차 입력 안내 멘트 출력 
- 경주할 자동차 이름 입력받기
  - 쉽표(,) 기준으로 구분 
  - 이름 검증
    - 5자 초과시 예외 발생
    - 공백일경우 예외 발생 
- 시도할 이동 횟수 입력 안내 멘트 출력 
- 시도할 이동 횟수 입력받기
  - 숫자 아닌 입력일경우 예외 발생
- 전진 기능
  - 랜덤값 기준 4 이상일 경우 전진
- 자동차 별 전진
- 실행 결과 출력 
- 입력받은 횟수만큼 반복
- 우승자 판별
- 우승자 출력
  - 공동 우승자의 경우 쉼표로 구분 
- 테스트 코드 작성 

### 프로그래밍 요구 사항
- 사용자가 잘못된 값 입력 시 `IllegalArgumentException` 발생 후 어플리케이션 종료 
- indent depth 2까지 허용 
- 3항 연산자 금지
- 함수가 한가지 일만 하도록 분리
